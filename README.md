# SAM
SAM for iQOO15 converts one whiteboard photo to working SQLite, FastAPI APIs, Docs &amp; Sheets in 20s offline. Uses PaddleOCR for handwritten tables &amp; Llama 3.2 3B Q4_K_M on NPU. Solves 3-4hr manual SQL/API work, zero cloud leak, no internet needed. Phone-first productivity for Bharat labs with weak internet, built for iQOO 15 hackathon. Team Parvaah.
